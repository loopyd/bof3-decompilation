# BOF3 documentation

Read [document contract](references/document-contract.md) before Markdown work.
Parent names authorized paths. Use native read/search/edit tools, not retired
harness Markdown transport. Operative knowledge stays in skill references;
user documentation is maintenance input, never required runtime reading.

## Protocol

1. **Bind scope.** Named Markdown only; no implicit repository-wide scan/edit.
   Find implementation/configuration/specification/policy owner for disputed facts.
   Analyzer prose and disposable `out/` state never supply reviewed truth.
2. **Read.** Read whole document, then reread immediately before editing. Preserve
   concurrent/unrelated work. For repair, first read
   [repair contract](references/documentation-repair.md).
3. **Edit.** Change authorized paths only. Preserve requirements, evidence gates,
   exceptions, dependencies, owners, stable IDs, unresolved work, provenance,
   commands, links and necessary examples. No relocation, source refactor or policy invention.
4. **Compact.** Cut redundancy; link single authority. Smaller bytes alone prove
   nothing. Prefer justified no-op over lost meaning. Historical/blocked work stays
   historical/blocked. Compact changed agent/skill prose directly; never restore
   retired agent-skill-compaction machinery.
5. **Validate.** Resolve edited links/anchors and affected indexes. Run applicable
   existing checks and `git diff --check`. Broken/unchecked references remain findings.
6. **Report.** Paths, actual changes, validation and outstanding gaps. Documentation
   scope grants no semantic source approval or deletion authority. Plan status,
   consolidation and recovery route to `$plans` with caller-supplied inputs.
