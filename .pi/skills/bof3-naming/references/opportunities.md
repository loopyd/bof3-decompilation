# Naming opportunities

```sh
bin/harness naming opportunities TARGET
bin/harness naming describe-opportunity TARGET ID --expected-fingerprint PIN
bin/harness agent context cleanup naming-opportunity TARGET ID
```

Read-only target-map raw function/data discovery; no index open/refresh, report,
source or map mutation. Invalid/missing target maps fail, never mean exhaustion.
Strict map parser preserves exact spellings/suffixes. Inventory enumerates raw debt,
not every improvable semantic name, shared symbol or type representation.

`bof3.naming-opportunity/v1` row: `id` as `TARGET@KIND:NAME`, `target`, `kind`,
`name`, actual mapped `address`, repo-relative `map`, `map_sha256`, `fingerprint`.
Fingerprint is `v1:` SHA-256 compact sorted-key JSON over other fields. Functions
then data by name, deterministic enumeration not semantic-value ranking/top-N.

Retain target/ID/fingerprint externally. Description requires current target
membership; expected pin rejects row/map drift. Unpinned scouting only. Any map byte
change invalidates leads; never silently repin. Non-atomic observation binds map,
not manifests/source/consumers/index. Success grants no downstream freshness,
useful name, evidence closure or mutation authority.

Unrelated open/unavailable access evidence still blocks conclusion despite positive
capability facts. Opportunity assessment cannot claim unfiltered `complete:true`.
Audit, evidence-backed proposal, separate identity approval, native verification
and rollback remain separate modes. Do not rewrite frozen requests/receipts after
skill-path migration. Missing/canonical report prerequisite blocks, never `init-all`
over retained history.

## Mission method

Use actual mission limits. One-target audit contract is not a universal three-row,
70-call or five-minute cap; those historical heuristics were unvalidated. Calibrate
against accepted units, evidence/review coverage and partial results. Serialize
report writers; held lock stops, never retry loop. Probe consequential premise
before delegation. Keep unsupported row blocked with smallest missing fact and one
bounded next command.

Match reviewer tools to required checks. Distinguish supplied evidence from personal
execution; unavailable required gate remains open. Compare against actual starting
dirty snapshot, not mtime or whole HEAD diff. Without snapshot, state attribution
limit. Separate weakened gate from insufficient evidence; writer self-check never
replaces independent acceptance.

Function ownership needs proven reviewed range/payload containment; data uses
map/load/layout and consumers, not empty function-owner results. Foreign spelling
is only lead until shared-map/recursive proof. Synthesized probe/receipt/replay flag
is not canonical run: payload, checkpoint and report-derived operation plan must
agree. Timeout 124 identifies deadline kill, not its layer; compare standalone
command time/bytes before blaming harness. Reproduce Rizin in actual invocation
mode; standalone `-c` and live stdin interactive flags differ.
