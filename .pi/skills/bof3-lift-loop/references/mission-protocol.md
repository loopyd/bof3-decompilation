# Mission and recovery protocol

## Freeze the handoff

Freeze finite queue, original deadline, attempt/repair limits, owner inputs and
external pins before delegation. Count delegation before issuing it. Resume keeps
consumption and frozen five-entry pilot unchanged. Active session owns queue
status; owner artifacts supply evidence, not another campaign database.

| Field | Required |
| --- | --- |
| Identity | Unique mission/stage, target-qualified selector or opportunity ID, complete membership/consumers |
| Route | One skill, explicit mode, predecessor results and dependencies |
| Scope | Read/write role, exact paths, shared inputs/exclusions, adopted dirty baseline |
| Evidence | Original bytes/load/layout; source/map/index/report pins; reviewed prerequisites |
| Bounds | Original deadline, remaining attempts/repairs; delegation counted before launch |
| Outcome | Checks, acceptance/no-op evidence, rollback authority, stop conditions |

Result binds actual session/tool handle, mission/selector, changed paths/content
pins, commands/outcomes, evidence, findings and proposed
`accepted|no-op|repair|blocked|deferred` disposition. Writer proposal never grants
parent acceptance. Missing, stale, malformed, failed or timed-out result cannot
advance successor. Unmeasured native outcome stays `unverified`/null; exit zero
alone proves no fidelity.

## Tooling, stop and resume

Harness commands remain deterministic tools, never agent launchers. Use owning
skill helpers/CLIs. Read `bin/harness decomp diagnose`/`audit` help and contracts
before constructing pinned inputs. They capture/check bounded missions only.
Local compiler subprocesses and existing supervision allowed; model subprocesses
prohibited. Never refresh inputs during an active pinned transaction.

Before native baseline compilation, follow
[native compiler execution](../../bof3-re/references/native-execution.md).
Known i386/SIGSYS host requires reviewed scoped parent-native tool call, not another
sandbox build or policy change. Missing approval blocks gates. Workers report
unverified; original bounds remain.

Observation timeout: poll same real handle. Stored PID, elapsed time, files or free
lease never prove termination. Interruption: retain POST/PRE/evidence/consumption;
establish writer termination/exclusion before owner recovery inspection and
approval. Never blindly reapply or restore unrelated work. Missing host handle:
inspect current state and report blocker; never recreate through CLI.

Exhausted bounds: close actual handles, hand off unfinished work without shrinking
goal. Completion requires whole-game coverage, 1:1 fidelity, human semantic
naming/type/macro acceptance, all supplied queue/milestone obligations and real
recovery/parallel-stage evidence. Tool availability, fixtures, green tests, one
exact function or fully accounted blocked queue cannot prove completion.
