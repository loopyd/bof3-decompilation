# toolchains

Downloaded or staged SDKs and compilers live here.

Examples:

- staged PsyQ under `toolchains/psyq-original/4.0/`
- PSn00b toolchain under `toolchains/psn00b_toolchain/`
- old gcc under `toolchains/gcc-2.7.2-psx/`
- canonical public ASPSX/PsyQ 4.0 bundle under `toolchains/aspsx-psyq-binaries/`
