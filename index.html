What these numbers mean

Progress counts target-qualified functions in the reverse index, not bytes or whole-game coverage. Completed means indexed exact status. Partial means an indexed lift with work remaining. Unlifted includes invalid lift metadata, which receives no progress credit. These declarations do not establish a fresh native build or runtime acceptance.

Symbols count indexed function and data map entries once per target and address, excluding aliases. Raw address labels match the naming tool's func_ and D_ patterns. Named counts all remaining spellings; it does not prove semantic correctness or complete symbol discovery. Targets without indexed symbols have no symbol percentage.
