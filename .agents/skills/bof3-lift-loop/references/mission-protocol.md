# Mission and recovery protocol

## Freeze the handoff

Freeze a finite queue and the fields below before delegation; count each launch
before issuing it. Resume original consumption and the frozen five-entry pilot.
Keep queue status in the active session/selected plan. Use owner artifacts as
evidence, never a campaign database.

| Field | Required |
| --- | --- |
| Identity | Unique mission/stage, target-qualified selector or opportunity ID, complete membership/consumers |
| Route | One skill, explicit mode, predecessor results and dependencies |
| Scope | Read/write role, exact paths, shared inputs/exclusions, adopted dirty baseline |
| Evidence | Original bytes/load/layout; source/map/index/report pins; reviewed prerequisites |
| Bounds | Remaining attempts/repairs; delegation counted before launch |
| Outcome | Checks, acceptance/no-op evidence, rollback authority, stop conditions |

Bind each result to the actual session/tool handle, mission/selector, changed
paths/content pins, commands/outcomes, evidence, findings and proposed
`accepted|no-op|repair|blocked|deferred` disposition. Parent acceptance remains
separate. Missing, stale, malformed or failed results block successors. Keep
unmeasured native outcomes `unverified`/null; exit zero alone proves no fidelity.

## Tooling, stop and resume

Use deterministic owner helpers/CLIs. Read `bin/harness decomp diagnose`/`audit`
help and contracts before constructing pinned inputs; they only capture/check
bounded missions. Use local compiler subprocesses and existing supervision, never
model subprocesses. Keep active transaction inputs pinned.

Reconstruction `run`, `capture-supplied` and `verify` share one cumulative
`reconstruction ledger` through `--attempt-ledger` and `--expected-ledger-digest`.
Reserve before owner calls; recapture never renews consumption. Retain missing
history explicitly and require a separate authorized allowance. Interrupted
epochs block execution until terminal-writer review; closing them refunds nothing.

Before native baseline compilation, follow
[native compiler execution](../../bof3-re/references/native-execution.md).
On a known i386/SIGSYS host, require a reviewed scoped parent-native tool call.
Missing approval blocks gates; report unverified within original bounds. Do not
repeat the sandbox build or change policy.

After an observation timeout, poll the same real handle. Stored PID, elapsed time,
files or free lease never prove termination. After interruption, retain
POST/PRE/evidence/consumption and establish writer termination/exclusion before
owner recovery inspection and approval. Do not blindly reapply or restore unrelated
work. If the host handle is missing, inspect state and report the blocker; do not
recreate it through CLI.

At exhausted bounds, close actual handles and hand off unfinished work without
shrinking the goal. Completion requires whole-game coverage, 1:1 fidelity, human semantic
naming/type/macro acceptance, all supplied queue/milestone obligations and real
recovery/parallel-stage evidence. Tool availability, fixtures, green tests, one
exact function or fully accounted blocked queue cannot prove completion.
