# Reverse mission protocol

Selector: `TARGET@0xADDRESS` or shipped EMI `BIN/FAMILY/ARCHIVE.EMI#INDEX@0xADDRESS`.
`bin/harness agent context reverse SELECTOR` preloads this file + tracked target evidence once; never reread bundled paths.

Before regional research read [regional leads](../regional-leads.md). Supplied EU
facts are hypotheses, not US address/behavior proof; verify against original bytes.
Return regional annotation evidence to parent; no unrelated browsing or edits.
Compiler-source research follows the matching ladder and owning build provenance.

## Steps

1. Reuse the brief; else run `function-brief.py` once. Before the first edit, check the [eligible-condition levers](../../SKILL.md#eligible-condition-levers): data/fragment evidence routes to classification or a parent-owned layout probe; a byte-identical sibling in another target that is already lifted routes to clone dry-run, while a span whose discriminating immediate appears only in its own target's binaries has no byte-identical sibling anywhere and is declined without an adapter call. A byte-identical twin whose own row is still `asm` has no source to clone, so prove the span equality with one payload `cmp`, decline the adapter, and seed from the nearest exact sibling, whose body differs only in that discriminating immediate. Near-identical siblings supply shape evidence, not clone proof. When the sibling differs only in stored literals, the constants its calls pass, a referenced symbol's address, the byte offset of a pointer-cell or record access, its test (an equality on a re-read cell versus an unsigned bound on the value just stored), the immediate of its own `j`/`jal` when the sibling sits at another address, or its returned value — or in those plus one call or store that only one side has, at a known position — copy its statement order, operand forms, offset-local spelling and declaration style, write this function's own literals, passed constants and symbol bindings from the original bytes, and take that one statement in the direction the original shows, adding the call or store it has or dropping the one only the seed carries; that has matched on the first gate, across targets as well as within one. One seed can draw on several siblings: take each region from the exact sibling that shows it, a saved-state group from one and a guarded tail from another, writing this function's own literals in both, rather than forcing one sibling's whole body. A mirror sibling qualifies on the same terms: it applies the inverse operation with inverted constants, so copy its statement order, operand forms, offset spelling and declaration style and write this function's own operator and constants from the original bytes. Measurements carried in the sibling's own metadata are that sibling's: take your own live diff before the first edit and ledger it as the baseline. Run only applicable levers, record declines, and use `m2c`/`m2ctx` only for a named remaining gap. Search target-owned declarations and `include/` before a bounded sibling search; never recurse from the repository root into generated/session trees. Honor `data_table_probe.warning` as a data lead, not classification proof: verify original bytes and request the parent-owned reviewed layout transaction; never move `.text` data into `rodata` in a lift lane. `bin/harness analysis data-candidates TARGET` ranks that same suspicion across a whole target before any lift is spent on it.
2. Before declarations: search per SKILL.md §Scope; no duplicates. Bind a new target-local fixed address by this precedence, checking composed Splat maps first: a `D_<ADDRESS>` name auto-binds with no map row; otherwise a source-local `extern` with `@source 0xADDR @kind data|unknown` plus a row in the target's own `symbols.txt`; a target-owned `*_symbols.c` `WEAK_SYMBOL_AT` only when the link fails on an undefined symbol. A table base that sits inside a longer reviewed pointer run binds at that interior word: declare the extern at the word the scaled index adds to and leave the run one row, since the generated `undefined_syms_auto.txt` row already names it. Generated PsyQ/support bindings may change through normalization and stay generated. A target-private `internal.h` is optional: it exists for several sources of one target sharing a declaration, and a single-function lift needs none. A referenced callee inside the target's code spans usually resolves from generated `undefined_funcs_auto.txt`, and a referenced fixed-address data pointer from generated `undefined_syms_auto.txt`; check both files before adding a map or `WEAK_SYMBOL_AT` row. Flipping a span from `asm` to `c` regenerates that file and drops the rows for callees only the asm referenced, so the link then needs their map rows; bind the owning target's canonical name with a `@source`-tagged prototype, because a raw `func_` row creates naming debt that the symbols check reports. That regeneration keeps the generated row of a `D_` data cell the new body itself declares and uses, measured with a control cell in a target that re-gated exact, so read the regenerated file before binding and add the target `symbols.txt` row only for the address the link reports missing; the row spells the raw `D_<ADDRESS>`, so the naming check reports it as raw-data debt until the parent-owned baseline adopts it. That canonical name retires the raw one elsewhere: re-point the `@source`-tagged prototype in each existing exact caller of the callee, then regenerate the manifest's `psyq_source` support file, which stops emitting the raw name's `WEAK_SYMBOL_AT` rows. A callee name is not encoded, so those callers keep their bytes, but their source changed and they join the gate batch. Address-taken users belong to that batch too: a body that publishes the callee into a slot holds it only as a stored address, so its bytes stay identical while its source changes.
3. For relevant declared companion calls run `companion-check` (static identity/call only, per SKILL.md §Scope). Never create foreign game bindings or source ownership.
4. Carry the ordered attempt ledger and outcomes through every repair. Preserve missing-history notes without blocking work on a quota. Repeat a tested lever only with changed evidence explaining its expected effect. A genuinely absent source follows the [first-source route](../match-loop.md#first-source). Before changing existing C: live normal diff, diagnose `first=`, one fix, rerun, revert regressions; ledger shape/class/result/retained. Reviewer retry: consume ranked experiments serially, record expected/actual effect + accept/revert, preserve the best; no evidence-free repeat; search [matching knowledge](../matching-knowledge.md) + exact siblings before retrying a lever, and re-run that sibling search when resuming a partial: an inherited note that no exact twin exists records the tree at the time it was written, so a twin lifted exact since then reopens the seed and can close the residual with no new spelling. Clean C only — the [clean-C terminal ladder](../../SKILL.md#match-loop) is the single home of its rungs; no register pins, clobbers or artificial barriers. Missing type/symbol role/field layout/caller contract/branch target/lifetime → focused Rizin rung first (`bin/harness analysis rz-project status TARGET`, `bin/harness analysis query` calls/xrefs/symbols, then target-isolated `bin/harness analysis rz-project open TARGET`); record what each supports/rejects; never use Rizin to force allocation or replace byte evidence. A caller the payload never names - no `jal`, no table word - is the overlay loader's entry, not a missing fact: record that absence and keep the argument roles structural instead of spending this rung on it. A caller named only by a word in the payload's script/data blob is a script-invoked callback, and the blob carries no prototype, so those roles stay structural too and no companion check is owed. Clean-C stall → report best scores, first-mismatch class and untried/blocked rungs. Keep the owning compiler and flags fixed. At a stall, follow compiler-source/RTL and bounded-runtime evidence branches before more source probes. Flag catalogs and compiler-variant batches are not matching rungs. Permuter work still requires selector-specific authorization; skipping it proves no exhaustion.
5. Evidence insufficient to lift: do not escalate before the focused Rizin rung. No global analysis, analyzer mutation or invented ownership. Snapshot stale → report parent-owned analysis required and keep working: while the global index refuses `analysis query calls`, the target-isolated `rz-project status`/`query` still answers size, frame, in-degree and caller evidence. Otherwise report target-qualified findings + next evidence.
6. Require the final live instruction/byte comparison and target symbol/Splat checks through the gate batch below; an exact workflow selector needs no redundant byte-verification reviewer. A new lift needs a `c` Splat boundary with `@source`/`@behavior`. No `just check`/`bin/harness lift status` in the mission. Retained map, reviewed Splat/annotation, or manifest source/support/header fact → `snapshot_index_refresh_required: true`; global analysis is prohibited here; the parent serially refreshes the snapshot, rebuilds the global index once, and checks both statuses.
7. Before declaring exhaustion apply the [exhaustion gate](../review/review-checklist.md): after the ladder and every failed experiment, search for safe untried candidates and record the searched evidence and rejection reasons. The [eligible-condition levers](../../SKILL.md#eligible-condition-levers) are that search surface: `analysis data-candidates` for a data-shaped range, `analysis carve` for a fragment boundary whose head lives in another segment or a bare `bin` blob, and `lift clone` for a range that is byte-identical to an already-exact function. Non-exact: restore regressions; leave the best coherent candidate + owned facts review-pending. Report baseline, best live diff / first mismatch / class, ledger, experiment effects, remaining candidates. The parent reviews, then continues from the complete ordered attempt ledger; restoration/sharing is parent-owned.
8. Retry reaches exact: report decisive experiment and prior partial diff for
   reusable-rule review. Never generalize register coincidence.

## Banned

Register pins (direct or `REGISTER_PIN`), clobbers, artificial barriers/empty asm, handwritten asm (except manifest-owned `WEAK_SYMBOL_AT`), asm-renamed externs, `INCLUDE_ASM` without approval, git writes, reset/clean/setup, children. Never delete/restore a non-exact best candidate before independent review; the parent owns post-review restoration.

## Return

```json
{"function":"TARGET@0xADDRESS","status":"exact|partial|escalated","match_percent":0,"files_changed":[],"matching_aids":[],"notes":""}
```

Append the required fenced `acceptance-report`: actual commands/validation, risks, pre-mission state, rung ledger, fresh staged-index state. Exact requires a live byte match + retained owned facts. Escalated requires a best coherent review-pending candidate, a truthful changed-file list, the live best diff, and `parent_restore_required: true`; never claim restoration.

## Lift setup order (once, before the first `asm-diff`)

1. Splat boundary `asm` → `c` with `@source`/`@behavior`. Those two annotation rows are not checked by the gate batch, which reads the C file's own tags, while the mission candidate check refuses a new lift whose boundary lacks `source` or `behavior`; confirm both rows by hand before gating. A row written as a single-quoted scalar takes no backslash escape, so an apostrophe in its prose spelled `\'` ends the scalar early: the gate then stops at registry/splat parse with no measurement, and the fix is annotation prose without apostrophes rather than another escape. When one `asm` row declares several functions, flip only the selected range and leave the rest as `asm` rows at the offsets its own endlabels already declare; relabelling the whole row to `c` claims the neighbours' bytes. A row also claims its forward slack: Splat sizes a `c` subsegment to the next declared start, so a body shorter than its row pulls the tail bytes into the claim, and a `0x3C` body inside a `0x40` row claimed four trailing zero bytes that no source produces; report that surplus as a parent boundary decision instead of padding the C to cover it. After the flip, `out/splat/<target>/asm/` keeps the old `func_<addr>.s` beside the stub generated for the new label while `linker.ld` names only the C object, so that leftover is generated-tree residue, not a boundary fault: leave it and report parent cleanup instead of deleting it or re-gating.
2. Target map row under the boundary's own name, `sym = 0xADDR;` (without it
   `asm-diff` cannot resolve the symbol). A raw `func_` row left beside a semantic `c`
   label refuses the first gate with `expected exactly one defined function symbol`;
   renaming that row cleared it with no body change. That rename retires the
   function's naming debt, so a stale `func_` entry for it in
   `config/symbol-naming-baseline.json` survives with the symbols check already
   passing: report it and leave the parent-owned baseline alone.
3. Manifest claim. `sources` and `support_sources` are both claimed and compiled, and every `sources` entry must carry function metadata, so a target whose `sources` is empty takes the lift in `support_sources` beside its generated psyq file.
4. Per referenced fixed address: target-local `extern` (`@source`/`@kind`) bound the way step 2's precedence selects rather than with a map row plus `WEAK_SYMBOL_AT`, and that target's map row when the name is not `D_<ADDRESS>` and no generated `undefined_syms_auto.txt` row covers the address because the asm spelled it as a literal; the omission fails the link naming the symbol, before any instruction measurement. Per referenced function: a target-local prototype, which keeps its `extern` keyword once it carries an `@source` tag, because the tag above a keyword-less prototype parses as that function's metadata block and the gate refuses at parse with `invalid_metadata: requires @behavior`, before any measurement.

Before first gate: evidence-backed name/module, complete ownership and canonical
metadata. Unknown roles stay address-anchored; `@status`/`@match`/`@residual` reflect
measurements. Placeholder tags (`@status partial`, `@match 0.00`) fail the gate on
byte-identical code, so write the measured tags in the same edit as the source
instead of spending a gate cycle on metadata alone. Name no tag inside prose: a
comment carrying `@behavior`, or `@source` alone on its own line above a definition,
parses as that function's metadata block and refuses the gate with `invalid_metadata`
before it compiles, while the same words after code on the line stay prose; delete
the token, since rewording around it still matches. After PASS, confirm naming
without rewriting correct source.
Later source/binding edit requires renewed gate.

## Gate batch (one pass, after all edits)

`bin/harness lift gate --target TARGET SELECTOR [SELECTOR ...]` performs one native measurement per selector (instruction and byte comparison) plus target symbol/Splat checks once. Do not repeat those checks for an unchanged candidate. Keep the pre-edit normal diff for existing C and applicable companion checks. Check the owned diff for whitespace: the gate's global diff check is informational, not a waiver. Gate retries handle recognized build races; no outer retry loop. Keep `symbols.txt` address-sorted. A first gate whose only failure is `<a claimed source of this target> (0xADDR) has no map address` reports target-map drift, not a body defect: that same gate already printed this selector's asm-diff measurement, so restore the missing rows of the target's own claimed sources, keep the map address-sorted and re-gate once; no clean-C probe is owed.

## Ranking fallback

`bin/harness analysis query --json quick-wins --target TARGET --unlifted --limit 8`.
Stale snapshot/index: rank tracked Splat `asm` boundaries minus every claimed
`@source` address by resolved calls, decisions, instructions; screen original
`div`/`break` traps. Parent owns refresh; never rebuild analysis in lane. Native
and target symbol/Splat checks remain available despite stale index.
