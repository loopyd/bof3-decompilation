Start here:

## Source Of Truth

- `docs/specs/`

  - generated extraction and planning artifacts
- `bof3/`
  - recovered or reimplemented PSX-first source
- `tools/python/`
  - repo-owned CLI and setup implementation
- `third_party/`
  - vendored external tools
  - CLI and setup implementation
