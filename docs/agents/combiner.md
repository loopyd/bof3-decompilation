# Source combining and cleanup

The [combiner skill](../../.agents/skills/bof3-combiner/SKILL.md) owns useful grouping,
direct source/claim/layout edits, consumer review and owned recovery. The harness
lists current facts and checks mechanical preservation.

```sh
bin/harness combiner list emi/etc/game/00 --limit 10 --json
bin/harness combiner check emi/etc/game/00 emi/etc/game/00@80197378 --json
bin/harness source metadata check emi/etc/game/00 emi/etc/game/00@80197378 --json
```

Every action requires one explicit target. Check selectors are canonical
`TARGET@ADDRESS` function IDs in that target. Omitting selectors checks the whole
target. A positive list limit truncates records only; scope, counts and findings
remain complete. Text and JSON report the same results. Exit codes are 0 for a
complete pass, 1 for findings or unavailable evidence, and 2 for an invalid request.

Listing reports authored members, source locations, reviewed sizes, configured
compiler profiles and current indexed calls, macro uses and type uses. Relationships
supply leads for the skill's judgment. A fresh existing index is required and listing
does not refresh it. A shared callee or lexical type name alone does not justify
combining source or expanding write authority.

Checks resolve every selected source member and possible callers. Foreign or
unidentified consumers remain explicit missing coverage. Source claims, attached
metadata, map bindings and Splat membership must agree. Grouped sources require one
explicit target owner and compatible effective per-function compiler settings.
Moved path defaults must retain their established settings through reviewed edits.
The check reports current settings; the skill compares them with its captured PRE.

Grouped native comparison freshly compiles the whole translation unit and places
each function at its reviewed address, including noncontiguous members. It compares
every complete finite aligned original range and declared initialized-data section.
A differing neighbor fails the selected comparison. Unknown or unsupported BSS,
computed jumps, relocations or placement remain blockers. Guarded absolute jump
tables require their established bounds and reviewed readonly data. Checks bind
current compiler programs, literal and forced includes, negative lookups, inputs
and output identities through execution. They grant no semantic acceptance or
persistent object reuse.

List/check actions never edit reviewed source, maps, metadata, claims or progress.
Native outputs are disposable. The skill preserves owned PRE, confirms process
termination before restoration and obtains independent review. Record an exact
match only after the existing live full-byte gate, then check the edited metadata.
Historical preservation and transaction records remain historical evidence.
